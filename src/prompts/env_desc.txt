The env object contains all problem data. env.G is a NetworkX graph where each node has lng, lat, and tourist attributes, and each edge has length, PI, and NI. Node neighbors come from env.G.neighbors(), and edge attributes from env.G.adj[u][v]. env.cost_matrix[o][d] is a dictionary with sum_dis, avg_pi, avg_ni, and sometimes path. env.flow[o][d] gives traffic flow. env.init_route is a dictionary of routes; each route has arc (list of node pairs), stop_num, and start_end. env.route_index is a list of route index ranges. You must only use these fields and not invent new ones.
